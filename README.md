# 智言 UI 自动化与 B1 业务探索

项目采用 Python、pytest、Playwright 和 Allure，页面对象位于 pages/zhiyan，配置位于 config/config.yaml。requirements.txt 当前固定 Playwright 1.49.1、pytest 8.3.4。本次浏览器探索使用 Codex 内置浏览器完成。

## 当前覆盖的含义

- tests/smoke：原有30个登记页面、237条只读功能场景、610个动作步骤。检查页面、入口、查询和弹窗，完成不代表业务结果通过；原运行前置仍为儒意官方旗舰店，不能把它的结果归属B1。
- data/b1/scenarios.json：2026-10-20的B1业务清单，共84条，包含业务目的、前置、步骤、验收点、实际观察、证据、状态及自动化范围。23条已验证具体操作、20条只检查入口或配置、41条未执行补测。
- tests/b1：12条保留样本的只读业务断言（原7条＋共享样本关联及专属知识4条＋共享知识恢复1条），固定开发站、天猫与B1；默认跳过、显式启用；复用请求拦截器阻止业务写入。不创建数据、不删除、不在测试窗发消息。只有本次观察中的部分验收点已转为断言，不能认为整条场景自动化完成。
- data/b1/runs/20261021.json：本轮11条增量用例，逐项记录预期、实际、证据及未执行原因；不会将部分检查提升为整个场景通过。
- tests/offline：环境与店铺隔离、危险请求拦截、清单执行状态真实性和证据完整性检查；不启动浏览器或联网。

## 离线验证

在项目根目录使用 PowerShell：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/offline tests/b1 -q -o addopts=
.\.venv\Scripts\python.exe -m tests.b1.catalog --write-report
.\.venv\Scripts\python.exe -m tests.b1.executions --write-report
.\.venv\Scripts\python.exe -m pytest --collect-only -q -o addopts=
```

第一条执行离线保护测试并跳过12条在线用例；第二条更新历史报告和矩阵，第三条从增量记录生成报告及手工用例；最后一条只收集用例。上述报告命令只读取本地JSON与证据。新增在线断言本次未运行终端浏览器，实际页面与业务结果由内置浏览器探索验证。

## 后续运行 B1 在线回归

将 UI_TEST_USERNAME、UI_TEST_PASSWORD 安全设置到本地进程环境；使用有B1访问权限的测试账号，不将真实值写进脚本、报告或命令记录。自动化只读环境变量，不自动读取探测脚本中的历史凭据，也不保存登录存储状态或认证trace。

```powershell
$env:TEST_ENV = "dev"
.\.venv\Scripts\python.exe -m pytest tests/b1 --run-b1-regression -q
```

需要安装 requirements.txt 对应依赖及 Playwright Chromium。发现选店错误、认证跳转或请求被保护器拦截时用例失败，不自动重试或并行。样本被手工改名、删除或配置变化也会失败，先核对测试数据再修正基线。

原只读冒烟的查看命令为 python -m tests.smoke.cli --list。其 --check 会启动本地浏览器验证运行器，本次没有执行该命令。tests/test_login.py 为 SauceDemo 示例，需另用 TEST_ENV=demo，不能混作智言登录验证。
